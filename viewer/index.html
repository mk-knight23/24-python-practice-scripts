What is this?

A collection of hands-on Python exercises. No frameworks, no dependencies. Just Python files you can run, edit, and learn from.

python cli/runner.py

--- basics ---

Variables, types, conditionals, loops. The foundation.

--- core ---

Functions, file handling, error handling. The tools you use daily.

--- advanced ---

OOP, decorators, generators. For when you need more power.

--- about ---

Design Notes

Intentional Quirk: The blinking cursor (█) appears everywhere. Not because it's needed, but because it reminds you: you're talking to a machine.

Tradeoff: No syntax highlighting. Color-coded keywords make code feel finished. Plain text makes it feel editable.

Limitation: No images, no icons. If you can't type it, it doesn't exist here.
